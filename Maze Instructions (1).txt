==============================================================
              MAZE ESCAPE - COMPILE AND RUN
==============================================================

Written in C++17 with SFML 3.x.


--------------------------------------------------------------
REQUIREMENTS
--------------------------------------------------------------

  - A C++17 compiler (g++ / MinGW-w64, clang++, or MSVC)
  - SFML 3.x (Graphics, Window, System and Audio modules)
    Download: https://www.sfml-dev.org/download.php

  Note: SFML 3 is NOT compatible with SFML 2.x code, so make
  sure you download version 3.


--------------------------------------------------------------
HOW TO COMPILE
--------------------------------------------------------------

arial.ttf and the .ogg music file must be in the same folder as
the executable when you run the game.

Windows (MinGW-w64 / g++)
  Assuming SFML is extracted to C:/SFML:

  g++ main.cpp -o main.exe -std=c++17 -IC:/SFML/include -LC:/SFML/lib -lsfml-graphics -lsfml-window -lsfml-system -lsfml-audio

  Copy the SFML DLL files from C:/SFML/bin (for example
  sfml-graphics-3.dll, sfml-window-3.dll, sfml-system-3.dll,
  sfml-audio-3.dll) into the same folder as main.exe, or add
  C:/SFML/bin to your PATH.

Linux
  Install SFML 3 (build from source or use a package manager
  that provides version 3), then:

  g++ main.cpp -o main -std=c++17 -lsfml-graphics -lsfml-window -lsfml-system -lsfml-audio

macOS
  clang++ main.cpp -o main -std=c++17 -I/path/to/SFML/include -L/path/to/SFML/lib -lsfml-graphics -lsfml-window -lsfml-system -lsfml-audio

Visual Studio Code
  1. Install SFML 3.x and a MinGW-w64 compiler.
  2. Open the project folder in VS Code.
  3. Update the include path in .clangd if your SFML folder is
     not C:/SFML.
  4. Build with the g++ command above (or a tasks.json that runs
     it).


--------------------------------------------------------------
HOW TO RUN
--------------------------------------------------------------

  Linux / macOS:   ./main
  Windows:         main.exe   (or just double-click it)

If the window opens but there is no text or music, check that
arial.ttf and the .ogg file are in the same folder as the
executable.
